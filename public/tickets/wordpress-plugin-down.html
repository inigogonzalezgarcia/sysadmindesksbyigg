Un plugin tumba la web corporativa

Practica cómo devolver a la vida una web WordPress en Docker Compose tras una actualización de plugin y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • WordPress en Docker Compose / una actualización de plugin
  • Prioridad P1 · SLA 20 min
  • Unos 15 minutos

Practícalo gratis

El ticket

Qué practicas

  • Leer los registros de un contenedor.
  • Comparar la versión de PHP y lo que pide un plugin.
  • Usar WP-CLI cuando WordPress no arranca.
  • Comprobar la web y el formulario.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.
