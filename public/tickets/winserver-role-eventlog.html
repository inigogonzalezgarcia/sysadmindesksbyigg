El rol de impresión se cae cada noche

Practica cómo leer los eventos de Windows Server para saber por qué el rol de impresión cae cada noche, resolverlo y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • Windows Server / rol de impresión y eventos
  • Prioridad P2 · SLA 30 min
  • Unos 15 minutos

Practícalo gratis

El ticket

Qué practicas

  • Leer los eventos del sistema y de aplicación con Get-WinEvent.
  • Relacionar la caída de un servicio con lo que la provoca.
  • Revisar colas y drivers de un servidor de impresión con PowerShell.
  • Comprobarlo con el trabajo real que fallaba.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.

Tickets to practise › Windows and Windows Server › Windows Server / print role and events

The print role falls every night

Practise how to read Windows Server's events to find why the print role falls every night, fix it and document it in the ticket.

  • Level 2 · second line
  • Windows Server / print role and events
  • Priority P2 · SLA 30 min
  • About 15 minutes

Practise it free

The ticket

What you practise

  • Read system and application events with Get-WinEvent.
  • Link a service crash to what causes it.
  • Review a print server's queues and drivers with PowerShell.
  • Check it with the real job that failed.

You solve it in a simulated console (PowerShell, cmd or bash) with the directory, the inventory and the ticket page. It is checked against the state of the system, not a template: hiding the symptom is not enough. When you close it you write the work note (cause, change, check and follow-up) and get your score.
