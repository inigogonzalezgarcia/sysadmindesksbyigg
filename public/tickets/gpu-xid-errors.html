Nodo GPU con errores Xid y trabajos que fallan

Practica cómo averiguar por qué fallan trabajos en un clúster de GPU, retirar el nodo averiado, gestionar el RMA y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • Clúster de GPU / una GPU con errores de memoria incorregibles que sigue recibiendo trabajos
  • Prioridad P2 · SLA 30 min
  • Unos 16 minutos

Practícalo gratis

El ticket

Qué practicas

  • Leer los errores Xid de NVIDIA.
  • Retirar un nodo de Slurm.
  • Pasar un diagnóstico DCGM.
  • Devolver el nodo al pool tras la prueba.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.

A GPU node with Xid errors and failing jobs

Practise how to find out why jobs fail on a GPU cluster, drain the faulty node, handle the RMA and document it in the ticket.

  • Level 2 · second line
  • GPU cluster / a GPU with uncorrectable memory errors that still takes jobs
  • Priority P2 · SLA 30 min
  • About 16 minutes

Practise it free

The ticket

What you practise

  • Read NVIDIA Xid errors.
  • Drain a Slurm node.
  • Run a DCGM diagnostic.
  • Return the node to the pool after a test.

You solve it in a simulated console (PowerShell, cmd or bash) with the directory, the inventory and the ticket page. It is checked against the state of the system, not a template: hiding the symptom is not enough. When you close it you write the work note (cause, change, check and follow-up) and get your score.
