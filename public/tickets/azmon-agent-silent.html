Un servidor dejó de enviar datos a Log Analytics

Practica cómo averiguar por qué un servidor con Azure Arc deja de enviar datos a Log Analytics, corregirlo y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • Azure Monitor / un servidor sin su regla de recopilación tras un traslado
  • Prioridad P3 · SLA 45 min
  • Unos 15 minutos

Practícalo gratis

El ticket

Qué practicas

  • Consultar el Heartbeat con KQL desde la CLI de Azure.
  • Revisar un servidor de Azure Arc y sus extensiones.
  • Entender las reglas de recopilación de datos.
  • Revisar el ámbito de las directivas de Azure.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.

  • Azure Monitor / a server without its data collection rule after a move

Practise it free

The ticket

What you practise

  • Query the Heartbeat with KQL from the Azure CLI.
  • Review an Azure Arc server and its extensions.

You solve it in a simulated console (PowerShell, cmd or bash) with the directory, the inventory and the ticket page. It is checked against the state of the system, not a template: hiding the symptom is not enough. When you close it you write the work note (cause, change, check and follow-up) and get your score.
