Creada en AD esta mañana, no aparece en Microsoft 365

Practica cómo averiguar por qué una cuenta nueva de Active Directory no llega a Microsoft 365 con Azure AD Connect, arreglarlo y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • Azure AD Connect
  • Prioridad P2 · SLA 30 min
  • Unos 20 minutos

Practícalo gratis

El ticket

Qué practicas

  • Seguir una cuenta desde Active Directory hasta Entra ID.
  • Revisar la configuración y el estado de Azure AD Connect.
  • Lanzar una sincronización y leer su resultado.
  • Comprobar que la cuenta existe en Microsoft 365.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.

Created in AD this morning, missing in Microsoft 365

Practise how to investigate why an account created in Active Directory does not reach Microsoft 365 through Azure AD Connect, fix it and document it.

  • Level 2 · second line
  • Azure AD Connect
  • Priority P2 · SLA 30 min
  • About 20 minutes

Practise it free

The ticket

What you practise

  • Follow an account from Active Directory to Entra ID.
  • Review Azure AD Connect's configuration and status.
  • Run a sync and read its result.
  • Check that the account exists in Microsoft 365.

You solve it in a simulated console (PowerShell, cmd or bash) with the directory, the inventory and the ticket page. It is checked against the state of the system, not a template: hiding the symptom is not enough. When you close it you write the work note (cause, change, check and follow-up) and get your score.
