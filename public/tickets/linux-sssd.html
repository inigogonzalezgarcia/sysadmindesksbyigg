El servidor SFTP de nóminas rechaza las cuentas del dominio

Practica cómo diagnosticar un servidor Linux unido a Active Directory que rechaza las cuentas del dominio por SFTP, arreglarlo y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • Linux / Active Directory
  • Prioridad P2 · SLA 30 min
  • Unos 20 minutos

Practícalo gratis

El ticket

Qué practicas

  • Diagnosticar un servidor Linux unido a Active Directory con SSSD.
  • Revisar los registros de autenticación del servidor.
  • Hacer el cambio mínimo en un servidor de producción con un plazo encima.
  • Comprobar que las cuentas del dominio vuelven a entrar.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.

The payroll SFTP server rejects AD accounts

  • Level 2 · second line
  • Linux / Active Directory
  • Priority P2 · SLA 30 min

Practise it free

The ticket

What you practise

  • Diagnose a Linux server joined to Active Directory with SSSD.
  • Review the server's authentication logs.
  • Make the smallest change on a production server against a deadline.
  • Check that domain accounts can sign in again.

You solve it in a simulated console (PowerShell, cmd or bash) with the directory, the inventory and the ticket page. It is checked against the state of the system, not a template: hiding the symptom is not enough. When you close it you write the work note (cause, change, check and follow-up) and get your score.
