Nadie entra por SSH al Ubuntu nuevo

Practica cómo recuperar el acceso SSH a un Ubuntu Server recién montado desde la consola de la VM y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • Ubuntu Server / SSH y cortafuegos
  • Prioridad P2 · SLA 30 min
  • Unos 15 minutos

Practícalo gratis

El ticket

Qué practicas

  • Revisar el servicio SSH y los puertos a la escucha.
  • Leer las reglas y el registro del cortafuegos ufw.
  • Abrir solo lo necesario y a quien lo necesita.
  • Comprobar el acceso en el registro del servidor.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.

Nobody can SSH into the new Ubuntu server

Practise how to get SSH access back to a freshly built Ubuntu Server from the VM console and document it in the ticket.

  • Level 2 · second line
  • Ubuntu Server / SSH and firewall
  • Priority P2 · SLA 30 min
  • About 15 minutes

Practise it free

The ticket

What you practise

  • Check the SSH service and the listening ports.
  • Read the ufw firewall's rules and log.
  • Open only what is needed, to whom it is needed.
  • Check the access in the server's log.

You solve it in a simulated console (PowerShell, cmd or bash) with the directory, the inventory and the ticket page. It is checked against the state of the system, not a template: hiding the symptom is not enough. When you close it you write the work note (cause, change, check and follow-up) and get your score.
