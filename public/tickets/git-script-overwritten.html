Tickets para practicar › Git / scripts del equipo

Alguien pisó el script de altas del equipo

Practica cómo recuperar con Git el cambio perdido de un script del equipo en una carpeta compartida y documentarlo en el ticket.

  • Nivel 2 · segunda línea
  • Git / scripts del equipo
  • Prioridad P3 · SLA 45 min
  • Unos 15 minutos

Practícalo gratis

El ticket

Qué practicas

  • Leer el estado y el historial de un repositorio Git.
  • Encontrar cambios que nunca se confirmaron.
  • Confirmar y subir un cambio con un mensaje claro.
  • Probar un script de PowerShell en seco antes de usarlo.

Lo resuelves en una consola simulada (PowerShell, cmd o bash) con el directorio, el inventario y la ficha del ticket. Se corrige por el estado del sistema, no por una plantilla: tapar el síntoma no basta. Al cerrar escribes la nota de trabajo (causa, cambio, comprobación y seguimiento) y recibes la puntuación.

Someone overwrote the team's starter script

Practise how to recover with Git a lost change to a team script in a shared folder and document it in the ticket.

  • Level 2 · second line
  • Git / team scripts
  • Priority P3 · SLA 45 min
  • About 15 minutes

Practise it free

The ticket

What you practise

  • Read a Git repository's status and history.
  • Find changes that were never committed.
  • Commit and push a change with a clear message.
  • Dry-run a PowerShell script before using it.

You solve it in a simulated console (PowerShell, cmd or bash) with the directory, the inventory and the ticket page. It is checked against the state of the system, not a template: hiding the symptom is not enough. When you close it you write the work note (cause, change, check and follow-up) and get your score.
